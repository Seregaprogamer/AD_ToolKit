# Checker получает неверный ответ / JSONDecodeError / поле text отсутствует

## Что могло произойти

HTTP 200 может содержать HTML или JSON с другой схемой.

## Что проверить

`curl -si URL`, `jq -e` для ожидаемого поля; посмотри первую строку тела и Content-Type. Сравни старую квитанцию.

## Что изменить

Верни контракт API и типы полей. При HTML проверь upstream и маршрут.

## Как проверить результат

Старый клиент успешно читает старую запись и создаёт новую.

## Как откатить

Верни предыдущее изменение обработчика отдельно от данных.
