# Практикум на 10 минут · заметки и чекер

**Цель:** восстановить интерфейс, сохранив записи. Нужен Python 3.8+ с модулями http.server и sqlite3. Интернет, Docker, sudo и pip не нужны. Выполняй команды из корня распакованного комплекта. Для второй вкладки открой тот же каталог.

### 1. Запусти свою копию

Терминал A:

```bash
LAB=$(mktemp -d "$HOME/ad-notes.XXXXXXXX")
echo "$LAB"
python3 06-LAB/service.py --state "$LAB"
```

Запомни напечатанный путь. Сервер слушает только 127.0.0.1:18765. В каталоге состояния появятся mode и notes.sqlite. Если порт занят, добавь `--port 18766` к **обеим** командам service.py и checker.py и поправь URL ниже.

### 2. Убедись, что данные сохраняются

В терминале B задай переменной LAB путь, напечатанный в A, например `LAB="$HOME/ad-notes.ABC12345"`. Затем:

```bash
python3 06-LAB/checker.py "$LAB/receipt.json"
python3 06-LAB/checker.py "$LAB/receipt.json"
```

Первый вызов создаёт запись через POST и читает её по ID. Второй сначала читает **предыдущую** запись, затем проверяет новую. Ожидаются сообщения `OK`. Квитанция локальная и относится только к этой базе. Для параллельных клиентов выбери разные файлы квитанций.

### 3. Сломай и восстанови контракт

```bash
printf '%s\n' bad-schema > "$LAB/mode"
curl -i --max-time 3 http://127.0.0.1:18765/health
python3 06-LAB/checker.py "$LAB/receipt.json"
```

На /health по-прежнему 200. Чекер сообщает, что поле text отсутствует или изменилось. Посмотри обработчик GET в service.py и журнал запросов в A. Почему повторное чтение старой записи сразу обнаружило проблему?

```bash
printf '%s\n' ok > "$LAB/mode"
python3 06-LAB/checker.py "$LAB/receipt.json"
```

Если видишь `OK: старая запись сохранилась`, интерфейс восстановлен без сброса данных.

### 4. Отличи простой от восстановления

Запиши `maintenance` в тот же файл mode. На этот раз /health ответит 503. Верни `ok`. Останови сервер через Ctrl+C, снова запусти той же командой в A с тем же LAB. Повтори чекер в B. После перезапуска старая запись должна читаться. Скопировать эту БД во время работы можно по [[07-BACKUPS/README|инструкции резервного копирования]].
