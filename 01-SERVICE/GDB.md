# GDB · почему программа выбрала эту ветку

Проследить ход выполнения своего ELF на небольшом примере с доступным исходником.

**Версия.** 17.2 на странице Kali.

**Зависимости и совместимость.** gdb, отладочная информация и бинарник своей архитектуры. Расширение pwndbg для данного упражнения необязательно.

**Офлайн-установка.** Системный пакет gdb; исполняемый modecheck приложен для amd64. На ARM64 собери его из C-исходника.

## Команды и проверка

```text
gdb --version
gdb -q 04-OFFLINE/amd64/modecheck
break check_mode
run maintenance
print mode
bt
finish
quit
```

Первые две строки вводятся в Bash, остальные в консоли GDB. Вызов check_mode возвращает 2 для maintenance. Из shell сравни с ready и проверь echo $?.

**Частая ошибка.** Если нет символов, собери cc -O0 -g 01-SERVICE/modecheck.c -o /tmp/modecheck и открой свой экземпляр. Ограничения ptrace в контейнере могут мешать отладке; локальный запуск проще.
