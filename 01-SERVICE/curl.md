# curl · запрос и время ответа

Сверить HTTP-метод, статус, заголовки, тело и задержку. Особенно полезен, когда браузер показывает общую страницу ошибки.

**Версия.** 8.14.1 в пакете; страница Kali указывает 8.21.0.

**Зависимости и совместимость.** curl; в комплекте приватные libcurl, TLS, сжатие и сетевые библиотеки. На amd64 требуется glibc ≥ 2.39.

**Офлайн-установка.** bash setup.sh из корня и строка export PATH из вывода; либо системный curl из кэша Kali.

## Команды и проверка

```text
curl --version
curl -si --connect-timeout 2 --max-time 4 http://127.0.0.1:18765/health
curl -sS -o /dev/null -w '%{http_code} %{time_total}\n' http://127.0.0.1:18765/health
```

В работающей тренировке сравни /health в режимах ok и maintenance. Должны отличаться коды 200 и 503.

**Частая ошибка.** Код завершения curl без --fail может быть 0 даже при HTTP 500. При 000 проверь stderr и адрес. Приватные данные в verbose-логах следует скрыть перед передачей.
