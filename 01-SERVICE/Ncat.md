# Ncat · вручную прочитать ответ протокола

Посмотреть, отвечает ли текстовый протокол на правильную строку запроса.

**Версия.** Ncat из семейства Nmap, страница Kali 7.99.

**Зависимости и совместимость.** Пакет ncat, сокеты TCP и shell printf. У команд nc и ncat на разных системах разные опции.

**Офлайн-установка.** Добавь именно ncat в репозиторий целевой Kali.

## Команды и проверка

```text
ncat --version
printf 'GET /health HTTP/1.0\r\nHost: localhost\r\n\r\n' | timeout 4 ncat 127.0.0.1 18765
```

Прочитай первую строку, затем отдели заголовки от JSON по пустой строке. Сравни с curl -i.

**Частая ошибка.** Без пустой строки сервер может ожидать конец заголовков. Текстовый запрос к TLS-порту не покажет HTTP.
