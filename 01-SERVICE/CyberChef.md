# CyberChef · декодировать учебную строку

Проверить представление обычных данных, например отличается ли текст от его Base64-кодировки.

**Версия.** v11.5.0 в официальном списке релизов.

**Зависимости и совместимость.** Для автономной сборки нужен современный браузер и полностью распакованный web-релиз.

**Офлайн-установка.** Заранее скачай архив приложения из Releases, распакуй со всеми ресурсами и проверь открытие в офлайн-браузере. В поставке готового CyberChef нет.

## Команды и проверка

```text
printf '%s' 'c3RhdHVzPW9r' | base64 -d
```

В поле Input вставь c3RhdHVzPW9r, в рецепт добавь From Base64. Ожидаемая строка status=ok. Терминальная команда даёт независимую проверку.

**Частая ошибка.** При пустой странице проверь, что распакованы ресурсы исходного ZIP. Ввод с переводом строки может менять результат обратного кодирования.
