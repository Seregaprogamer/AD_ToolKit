# ripgrep · поиск по исходникам

Найти точную строку ошибки, обработчик запроса или использование переменной в своём проекте.

**Версия.** 15.2.0 в комплекте, сборка e89fff89ac.

**Зависимости и совместимость.** Статический Linux ELF amd64; на ARM64 нужен системный rg либо grep.

**Офлайн-установка.** Извлечение через bash setup.sh либо dpkg-deb -x, см. установку.

## Команды и проверка

```text
rg --version
rg -nF 'notes.sqlite' 06-LAB/service.py
rg -n 'do_GET|do_POST' 06-LAB/service.py
```

В корне комплекта найди обработчик POST и прочитай SQL-запрос рядом. Для поиска файла по имени используй rg --files.

**Частая ошибка.** Файлы, исключённые .gitignore, могут отсутствовать в результатах. Для собственного конкретного файла укажи путь явно. Буквальный поиск выполняется с -F.
