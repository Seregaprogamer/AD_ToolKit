# Burp Suite Community · журнал штатных запросов

Увидеть, какой путь и заголовки посылает браузер своему учебному приложению.

**Версия.** 2026.8 на странице Kali.

**Зависимости и совместимость.** Графическая сессия и поддерживаемая среда Java или комплектный runtime официальной сборки.

**Офлайн-установка.** Дистрибутив не вложен. Заранее установи Community на своём ноутбуке из официального источника или используй доступный пакет своей Kali.

## Команды и проверка

```text
burpsuite --version
burpsuite
```

Proxy → Intercept off → Open browser. Открой http://127.0.0.1:18765/health, затем Proxy → HTTP history. Выбери запись и прочитай вкладки Request и Response.

**Частая ошибка.** Если запрос завис, проверь Intercept. Если истории нет, проверь фильтр истории и используй встроенный браузер. Для упражнения достаточно HTTP без настройки сертификата.

[Официальная документация](https://portswigger.net/burp/documentation/desktop/tools/proxy/http-history)
