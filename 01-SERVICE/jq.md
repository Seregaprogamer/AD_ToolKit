# jq · проверить контракт JSON

Проверить имена и типы полей, которые получает клиент.

**Версия.** 1.7 в комплекте.

**Зависимости и совместимость.** jq и libjq, регулярные выражения libonig, glibc ≥ 2.39 для включённого комплекта.

**Офлайн-установка.** bash setup.sh и напечатанный export; ARM64 — пакет jq из соответствующего кэша.

## Команды и проверка

```text
jq --version
printf '%s\n' '{"status":"ok"}' | jq -e '.status == "ok"'
curl -fsS http://127.0.0.1:18765/health | jq -e '.status == "ok"'
```

Проверь, что фильтр для status возвращает true. Замени вход на {"state":"ok"} и проверь код завершения через echo $?.

**Частая ошибка.** Без -e вывод false не означает ненулевой код процесса. Для пайплайна в Bash используй set -o pipefail, иначе ошибка curl может скрыться.
