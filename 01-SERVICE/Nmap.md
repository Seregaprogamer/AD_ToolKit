# Nmap · проверить объявленный порт

Проверить TCP-порт собственного стенда с позиции клиента после изменения привязки.

**Версия.** 7.99 на странице Kali.

**Зависимости и совместимость.** Пакет nmap и его данные; для примера TCP connect административные права не нужны.

**Офлайн-установка.** Пакет nmap и зависимости через локальный кэш Kali.

## Команды и проверка

```text
nmap --version
nmap -n -sT -p 18765 127.0.0.1
```

Запусти сервис из 06-LAB. Сравни результат для одного порта до запуска и после. После open проверь HTTP через curl.

**Частая ошибка.** closed — TCP получил отказ; filtered может означать фильтрацию или отсутствие ответа. Сверь с ss на хосте и тайм-аутом клиента.
