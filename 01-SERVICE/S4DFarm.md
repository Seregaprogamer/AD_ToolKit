# S4DFarm · состояние фермы

Командная ферма S4DFarm развёртывается отдельно от учебного комплекта. Открой терминал в каталоге **уже развёрнутой фермы**, где лежит её `compose.yml`. В каталоге `03-DOCKER` эти команды покажут учебный сервис заметок.

| Что проверить | Команда | Как читать результат |
|---|---|---|
| Какие компоненты описаны | `docker compose config --services` | Имена из списка можно использовать для просмотра журналов. |
| Что сейчас работает | `docker compose ps -a` | Посмотри состояние контейнера и опубликованный порт. Для доступа к панели команды нужен порт хоста. |
| Почему компонент перезапускается | `docker compose logs --since 5m --tail 100 ИМЯ` | Вместо ИМЯ подставь компонент из первой команды. Найди первую ошибку до сообщения о перезапуске. |

Если список компонентов верный, а контейнеров не видно, проверь выбранный Docker context командой `docker context show`. Если панель доступна, но клиент Neo сообщает об ошибке, перейди к [[01-SERVICE/Neo|диагностике Neo]].
