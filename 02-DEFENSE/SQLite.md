# SQLite · проверить локальные данные

Проверить, что работающий сервис пишет в ожидаемый файл, и сделать согласованную копию.

**Версия.** Версия встроенной библиотеки определяется sqlite3.sqlite_version.

**Зависимости и совместимость.** Python 3 с модулем sqlite3 или отдельный sqlite3 CLI.

**Офлайн-установка.** Лаборатория использует стандартный Python-модуль; CLI из пакета sqlite3 опционален.

## Команды и проверка

```text
python3 -c 'import sqlite3; print(sqlite3.sqlite_version)'
```

После запуска лаборатории используй пример online backup из 07-BACKUPS. Сравни количество записей и проверь предыдущую квитанцию на отдельной копии.

**Частая ошибка.** Обычный sqlite3.connect с опечаткой в пути может создать пустую БД. Для чтения используй URI с mode=ro.

[Официальная документация](https://docs.python.org/3/library/sqlite3.html)
