# Если пропала сеть

1. Зафиксируй точку наблюдения. Проверь только адрес собственного сервиса из брифинга или адрес своей домашней лаборатории. Для Docker различай ноутбук, игровой хост и сетевое пространство контейнера.
2. `ip -br link` → интерфейс поднят? `ip -br addr` → есть адрес? `ip route get IP` → верные dev и src? Если маршрут неверен, сохрани вывод перед сменой профиля.
3. Если адрес задан именем, выполни `getent ahosts ИМЯ`. Для внутреннего имени базы проверь его со стороны приложения в той же Compose-сети.
4. Проверь конкретный опубликованный порт. Отказ сразу, тайм-аут и полученный HTTP 503 — разные результаты. Сверь с логами по времени. Отсутствие ответа на ICMP само по себе не доказывает, что HTTP недоступен.
5. После исправления повтори исходный запрос и полный пользовательский сценарий. Зафиксируй маршрут, код и время. [[10-TROUBLESHOOTING/Network|Расшифровка ошибок и откат]]
