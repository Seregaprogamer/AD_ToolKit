# ip и ss · интерфейс, маршрут, порт

Быстро определить, где обрывается соединение со своим сервисом.

**Версия.** Версию своего пакета показывает ip -V.

**Зависимости и совместимость.** iproute2 и Linux с Netlink; чужие PID в ss без дополнительных прав могут скрываться.

**Офлайн-установка.** Пакет iproute2 в локальном кэше.

## Команды и проверка

```text
ip -V
ip -br addr
ip route get 127.0.0.1
ss -lntp
```

Запусти тренировку и найди LISTEN на 127.0.0.1:18765. Для сервиса на другой машине посмотри выбранный исходящий интерфейс и адрес src.

**Частая ошибка.** 127.0.0.1 внутри контейнера указывает на этот контейнер. Пустое поле Process у ss не означает отсутствие слушателя.

[Официальная документация](https://man7.org/linux/man-pages/man8/ss.8.html)
