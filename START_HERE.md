# Главная · AD Survival Toolkit

> [!tip] Первый запуск
> Открой папку **AD-TOOLKIT** как хранилище. Если приложения ещё нет, начни с [[04-OFFLINE/Obsidian/README|установки Obsidian]]. Все команды в примерах выполняются из корня комплекта, если в заметке не указан другой каталог.

## До соревнования

- [ ] После распаковки выполни `bash verify.sh` и `bash check.sh`.
- [ ] Пока есть интернет, скачай Obsidian и проверь открытие этого хранилища на Kali в офлайн-режиме.
- [ ] Пройди [[06-LAB/README|тренировку с чекером]]. Быстрая проверка комплекта — `python3 06-LAB/selftest.py`.
- [ ] Если понадобятся комплектные CLI на amd64, выполни `bash setup.sh`. Для Docker есть [[03-DOCKER/README|локальная лаборатория]]. Для ARM — [[04-OFFLINE/arm64/README|отдельная памятка]].

## Во время раунда

- **Только началась игра** → [[05-KNOWLEDGE/05-min|первые 5 минут]] → [[05-KNOWLEDGE/15-min|15 минут]] → [[05-KNOWLEDGE/30-min|30 минут]].
- **Есть текст ошибки** → Ctrl+Shift+F → введи `tag:#ошибка "Connection refused"` или открой [[10-TROUBLESHOOTING/INDEX|каталог ошибок]].
- **Сервис упал** → [[02-DEFENSE/SERVICE-DOWN|проверить доступность]]. **HTTP 200, но на табло красный** → [[02-DEFENSE/CHECKER|проверить контракт чекера]].
- **Нужен откат** → [[07-BACKUPS/README|копия и восстановление]] → [[02-DEFENSE/HANDOFF|журнал изменений]].
- **Нужна команда** → [[09-CHEATSHEETS/ROUND|шпаргалка раунда]] или Ctrl+O и название инструмента.
